# Anymoon · prévia

Site de apresentação de Giovanna, a Any (@anymoon_ink): microrrealismo colorido, releituras de obras de arte e a coleção autoral Jardim da memória. Feito por [L R G Z](https://lrgz.com.br).

Conceito: "o retrato se pinta". Na abertura, cerca de 35 mil pinceladas curvas seguem o fluxo do retrato dela, no jeito Van Gogh das releituras. Começa por uma aguada de aquarela e termina no rosto. Leva 4,9 s e depois para. "Any" fica à esquerda da pintura e "moon" à direita, no eixo. A paleta (papel, tinta, oliva, rosa e ouro) e as fontes (Cormorant, Imperial Script) foram tiradas do material dela.

## Como montar

```
python tools/pinceladas.py      # pinceladas do retrato (assets/hero/pinceladas.bin)
python tools/fotos.py           # fotos do portfolio, disponiveis, cicatrizadas, loja e dados.js
python tools/gerar_video.py     # MP4 do celular, final.webp, capa do link e favicon
python tools/auditar.py         # 13 tamanhos + teste funcional
python tools/telas.py           # capturas de tela
```

O material original (Instagram, destaques, loja e obras em domínio público) fica fora do repositório, em `../_ref`.
